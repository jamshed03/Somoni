title: Functions and lambdas
intro: Functions have types for their parameters and their result. Lambdas may leave them out where they are known.
note: map, filter, reduce, any, all and sort_by give the lambda its types
note: Lambdas copy the outside variables they use
---
fn square(x: int): int {
    return x * x;
}

var users = [User { name: "Ali", age: 30 }];
print(users.map(fn(u) => u.name));
print(users.filter(fn(u) => u.age > 18));
