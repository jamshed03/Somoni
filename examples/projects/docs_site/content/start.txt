title: What is Somoni?
intro: Somoni is a strongly typed language with curly braces. A type checker finds errors before the program runs, a VM runs the bytecode.
note: Run a program: somoni file.smn
note: Named after Ismoil Somoni
note: Interpreter written in Rust: lexer, parser, type checker, compiler, VM
